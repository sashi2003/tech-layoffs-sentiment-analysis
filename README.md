# Tech Layoffs Sentiment Analysis

## Overview
An end-to-end NLP project analyzing tech layoff trends and media 
sentiment from 2020 to 2026. Combines structured layoff data with 
NLP sentiment analysis and topic modeling to uncover patterns in 
how the tech industry and media respond to economic disruption.

## Project Structure
- `notebooks/` — Analysis notebooks (EDA, Sentiment, Topic Modeling, Correlation)
- `data/` — Datasets (layoffs, news sentiment, labor indicators)
- `app/` — Streamlit dashboard

## Tech Stack
Python, Pandas, Plotly, HuggingFace Transformers, BERTopic, Streamlit

## Key Questions
- Which industries and companies were hit hardest by layoffs?
- How does media sentiment correlate with layoff announcements?
- What topics dominate tech layoff news coverage?
- Can we predict layoff spikes from economic indicators?
